# Sound effects

Built by `tools/build_sfx.py` (trimmed, faded, peak-normalised, mono MP3).

Source: `binaries/data/mods/public/audio` in https://github.com/0ad/0ad.

## uisfx — CC0 1.0

`ui_*.mp3` (except `ui_select_1.mp3`), `coin_*.mp3`, `reward_*.mp3`, `level_up_*.mp3` and `travel_*.mp3` come from the
[uisfx](https://www.npmjs.com/package/uisfx) package ("organic" and "cinematic" styles),
dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

## Supplied clips

`ui_select_1.mp3` is "Mouse Click" by Universfield (sound 117076), supplied with the project;
the original is kept in `tools/sfx-src/`. The file name follows Pixabay's download naming, so it
is presumably used under the [Pixabay Content License](https://pixabay.com/service/license-summary/).

Dice rolls are synthesised in the browser (`js/sfx.js`).
